# Svadbeni Salon Rimac — desktop (Flutter)

Admin aplikacija: katalog (ponude, meniji, artikli, muzičari, dekoracije, žanrovi),
svadbe, dnevni sastanci, uplate/računi, izvještaji (PDF), zaposlenici.

## Pokretanje

```bash
cd UI/desktop
flutter pub get
flutter run --dart-define=API_BASE_URL=http://localhost:5121
```

Test korisnici (lozinka `test`): `desktop`, `admin`, `zaposlenik`.
Detalji u root `README.md`.
